0 개요 Seoro는 오프라인 기반 행사 플랫폼. 슈퍼어드민은 플랫폼 전체를 운영·관리하는 내부 운영자 전용 화면 (PC 전용).

단일 계정 체계: 하나의 계정이 호스트그룹 구성원, 청중, 연사 역할 동시 가능.
1 Host 레이어 행사를 주최하는 그룹의 운영 화면.
2 청중 레이어 행사 참가 및 네트워킹 모바일 앱 화면.
3 슈퍼어드민 내부 운영자 전용 PC 화면. 행사 기본 정보(호스트 입력 필드 전체)는 슈퍼어드민 내 재구성하지 않고, 호스트 페이지에서 직접 열람 가능.
4 메뉴 구성 6개 메뉴로 구성. 좌측 사이드바 네비게이션으로 전환.

핵심 권한:
• 호스트그룹 생성 신청 승인/반려
• 전체 회원 조회 및 제재 (정지/해제)
• 호스트그룹 구성원 추가/역할 변경
• 행사 취소 신청 승인/반려
• 네트워킹 키워드 설정 (행사 단위, 8개)
• 홈 노출 행사 큐레이팅 및 순서 관리
• 행사 카테고리 CRUD
